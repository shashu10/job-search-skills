# Changelog

## 0.3.0 — 2026-10-25

- Lead with four entry points: Find Jobs Worth Applying For, Find Referrals, Interview Coach and Offer Negotiator. Preserve all ten skill IDs and automatic discovery.
- Add explicit shortlist review and recorded pursue/pass/hold decisions while reusing scoped application grants.
- Add referral sweeps across applied roles, prioritizing personal contacts and existing connections before public discovery.
- Broaden interview coaching to questions, lessons, reviews and mocks before an invitation; broaden negotiation to compensation questions and prospective scenarios before an offer.
- Clarify supporting resume/application work and inbox handoffs. Update private templates, onboarding and the fictional walkthrough.
- Add natural-request evaluations that select from the full catalog and exercise cross-skill handoffs using fictional evidence.

## 0.2.0 — 2026-10-25

- Add resume, inbox reconciliation, offer evaluation and requested scheduling skills.
- Update the original six workflows with shared routing, broader discovery, factual corrections, concise review defaults and interview learning.
- Add blank private records for interview preparation, offer details, inbox coverage and schedules.
- Add a fictional walkthrough and independent decision scenarios.
- Extend privacy screening and initialization tests; add CI for Python 3.10 and 3.13.
- Prepare the first public release. The optional dashboard remains planned; this release supplies skills and a workspace initializer, not a connected application or scheduler.

## 0.1.1 — local preview

Six portable skills, blank private-workspace templates, initializer, MIT license, plugin metadata and structure tests. This preview was prepared locally before public release.
