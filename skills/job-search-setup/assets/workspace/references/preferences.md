## Workflow limits

Default to one active browser session/tab and one form mutation at a time until the user sets a different resource budget. Preserve user tabs and unfinished forms. This is an adjustable workspace default, not a platform restriction. Delegate independent local work where useful. If several chats or scheduled jobs share a recruiting browser, configure a shared lock with owner/run, scope and start time; release only the holder's lock and verify the owner has stopped before clearing it. Lock age alone does not prove it stale. A free lock does not prove an unfinished form is safe to replace.

Reuse suitable approved materials. Prefer a rendered PDF unless a recipient or user needs another format. Use an existing document workflow where available; do not invent a new renderer per role.
